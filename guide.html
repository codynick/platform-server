Your Workspace

Your files, output, Blockly designs, dashboard and simulation belong to your account. Run starts or replaces your own program; Stop stops only your program.

First Test

Open Python IDE, create a file, enter this code and press Run This File:

import time
for number in range(10):
    print(number)
    time.sleep(1)

Gadget Simulation

Open Gadget Simulator in another tab. In the IDE, open CodyNick examples/simulator/simulator_demo.py and run it. This uses simulated gadgets, not real USB hardware. For a multi-gadget example, add the required gadgets to the stage first.

Dashboard

import time
import Dashboard
Dashboard.clear()
card = Dashboard.Card("info", "Counter", value=0)
for number in range(100):
    card.set(number)
    time.sleep(2.5)

Open Dashboard in another tab using this account's same address and port. Another account has a different dashboard.

Block Coding

Use General, Sprites and Hardware categories. Save/Load stores named designs in your workspace. Run starts the generated Python. Stop leaves other accounts alone.

Physical Hardware

A real CJP requires USB passthrough into a virtual machine. Only one process can open each serial port at a time. Stop the current hardware program before another user tries it.

Limits

No AI runtime is installed. This is for trusted classroom users on a trusted local network, not an Internet-facing service. Accounts share one Linux execution identity; deliberate access to another user's data from Python is not prevented. HTTP passwords are not encrypted without HTTPS. Closing the browser does not stop your program. Use Stop before leaving.
